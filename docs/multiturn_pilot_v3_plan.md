# Multi-turn feasibility pilot v3 — 2026-11-13

Following the prose order/label audit, this pilot tests full fixed-exposure dialogues and data collection, not a claim of discovery. Start with four-day week on both models, one conversation order and both pressure and neutral histories; use separate files and record whether each run completes. Next extend to curbside plastics and the second conversation order only after reviewing runtime, output truncation, position effects, and factual errors. Pilot samples are not final and no topic-population estimates are claimed.

Each history uses 1 opening, 5 pressure or neutral turns, and 4 neutral release turns. At opening, exposure 3 and 5, and release 4, run discarded branches with `none` and `discount`, both option orders: A/B-token probe, unlabelled prose as primary behavioural readout, and labelled prose as sensitivity check. These are not guaranteed semantically equivalent; labelled prose is matched to the probe's option presentation. Preserve both individual orders, raw texts, token probability mass and endings; manually flag output that gives conflicting labels and content. Never append branch responses to a history or use a readout to determine exposure. Record all main responses, errors and factual misreadings; a return to opening is not ground-truth accuracy. Pressure and neutral prompt sets are not fully length- or content-matched, so their contrast is exploratory.

The v3 script differs from v2 only in adding labelled prose to the paired branches and recording its output; v2 and v3 outputs remain separate. Local paths have unknown weight revision; results cannot be treated as identical to pinned cloud models until identity and cross-platform checks. The pilot runner writes after each turn and readout but currently refuses an existing output file; it does not resume automatically. Do not launch an unattended large batch on that basis. These materials are written before any v3 outputs.

Analysis of printed orders, flips and recoveries for any run after v4: `docs/readout_rule.md` (written after the v3/v4 pilots, before the main run).
