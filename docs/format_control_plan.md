# Readout-format diagnostic — pilot

Purpose: on identical stored histories, isolate displayed option labels in prose and compare letter/prose output under matched labelled options. These are selected diagnostic histories, not a population sample or a new-dialogue experiment.

Four frozen histories: four-day week and curbside plastics, each opening and first selected pressure checkpoint (conversation order 1). Both Llama 3.1 8B and Qwen 2.5 7B read the same four Llama-generated histories; Qwen is not a reproduction of a Qwen-generated conversation. Each checkpoint has 3 branch formats × 2 option orders × discount on/off, with greedy decoding. A: labelled options, letter-only probe; B: same labelled options, prose; C: unlabelled bullet options, prose. B and C differ in labels/punctuation; A and B differ in output instructions. Measure B–C within a checkpoint and compare orders; manually inspect all ambiguous or inconsistent prose, letter echo, option position, truncation, probe mass. Report opening and pressure separately, model and topic individually. Do not equate probabilities with binary prose, claim the differences reveal internal beliefs, assume label effect is exclusively anchoring, or generalize from four chosen histories. Opening histories already contain option letters; this test does not isolate the impact of labels in the earlier conversation. Do not interpret v1-v2 changes as controlled estimates.

Use local models already present, MPS and bfloat16 as loaded; hash tokenizer and record software/runtime. Exact local weight revision is unknown: results are pilot comparisons, not a verified replay of pinned Hub weights. Save each branch atomically with exact prompt, source prefix hash, raw text, label, timing, probability mass and options. Never add readout text to main history. Resume only same identity; partial output is not complete. Check ≥0.9 mass and EOS separately; review parsing manually.
